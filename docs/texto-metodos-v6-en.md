# Draft methods text for iSys (V6 candidate, without fabricated results)

The confirmatory benchmark was prospectively prepared as a new set of 36 purposively authored synthetic source families (G01–G36), distinct from the F01–F26 families used during the preceding corrective replication. Each eligible family defines an OWL/XML source overlay and three related FHIR Bundles: a reference conversion, a semantically equivalent control, and one deliberately altered variant. Six families define intentional converter refusals and are evaluated separately. Source data and expected semantics were specified before any official V6 validation. The ontology source file was read to verify its declared schema but was not modified or included in the distributed benchmark. The 26-family confirmatory partition was held without semantic scoring during preparation; the ten remaining families served for development checks.

Condition A measures deterministic ontology-to-FHIR transformation and explicitly reports coverage and refusals. Condition B adds validation against the HL7 FHIR R4 (4.0.1) base Bundle profile with the official Validator CLI 7.0.3 and the fixed `hl7.fhir.r4.core#4.0.1` package. Condition C adds source-relative checks of examination identity, patient association, result content, units, temporal precision, and equivalence of five competency-query classes. Structural errors and semantic divergence are recorded separately, and neither detection nor rejection is treated as automatic correction. A candidate family's comparisons are not included in the differential detection denominator when its baseline Bundle fails official validation.

The unit of analysis is the source family, not its derived variants. Detection under B and C is compared as a paired family-level outcome. Reference and equivalent controls support an explicit estimate of false-alarm behavior, with invalid controls reported separately rather than reclassified post hoc. For execution cost, official validator latency and incremental semantic-check time are measured as distinct processes; warmed, repeated local runs of the semantic comparison are summarized at the family level and are not counted as independent cases.

**Reporting restriction:** The V6 materials currently constitute a *candidate* confirmatory design. Independent review by a FHIR specialist, official validation, final metrics, and interpretations are pending. No outcome or validation rate for the V6 confirmatory partition should be asserted until those activities are complete.
